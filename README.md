# GSoC 2025 – LibreOffice Writer: Table Styles UI/UX Improvements

## Project: Enhancing Table Styles in LibreOffice Writer

This repository contains all documentation, code experiments, and planning related to my GSoC 2025 proposal with *LibreOffice. The aim is to significantly improve the **user interface and workflow for table styles in Writer*, making the feature more accessible, powerful, and user-friendly.

---

## Project Overview

LibreOffice Writer allows users to apply table styles, but the existing interface is outdated and lacks real-time feedback or deeper customization. This project proposes:

- A complete redesign of the *Table Style dialog UI*
- Adding *real-time preview* of styles
- Introducing *advanced customization options* like padding, spacing, borders, and background
- Streamlining the *workflow* to apply, edit, and create table styles easily
- Improving the *backend structure* if needed to support new features
- Maintaining *format compatibility* with ODF and DOCX

---

## Main Goal

> The primary goal is to *enhance the user experience of table styles in LibreOffice Writer* by modernizing the UI, improving interactivity with live previews, and expanding customization capabilities – making it easier for users to format tables with consistency and ease.
